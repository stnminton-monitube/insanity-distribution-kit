Auto-draft from your edit

In Premiere: click the timeline, then File → Export → Final Cut Pro XML on your final sequence, and load it here. Every audio and video track shows up below — nothing is pre-picked. Tick which audio track(s) to pull from, then every clip on those tracks appears underneath with its track and filename so you can check off which ones are actually music. Tick video tracks that are graphics/titles the same way. It drafts the Music Cue Sheet, Lower Thirds Log, and Textless Materials Log. Load your caption file to draft the As-Broadcast Script.

Any video clip whose filename matches gets added to the Lower Thirds & Textless logs, whatever track it's on — this same pattern also decides which clips get swapped when building the textless sequence, below. The default already covers this show's real graphic types (Lower Thirds, Photoviewer, OnWall, Blackout, etc.) and — the durable part — matches any render farm output by its _Default/_Alpha filename suffix, so a brand new graphic type gets caught automatically without ever touching this field. Add more terms with | only if something's still getting missed.

Stem Assembler

Export five audio-only WAVs from your sequence (48kHz/24-bit stereo, via track solos): FULL (everything), NARR (narration only), DX (all spoken content), MX (all music), FX (all effects). The app builds the 16-track layout — stem-based 5.1 (C = dialogue+narration, LFE low-passed, surrounds −6dB), Lt/Rt, FX/MX/M&E pairs, narration, mono — then embeds it into your program video so QC passes fully.

Render Farm

Scan finds your After Effects projects, grouped by graphic type. Each one is a single row in that project's MGX: Notion database — texted and text off are tracked as two independent statuses on that SAME row, so you can queue either or both together in one batch. For text off, the app first opens the project locally just to disable its text layers (real text layers auto-detected; name baked text layers with a TXT_ prefix or label color 9 (green)) and saves a _TEXTLESS.aep copy beside the original — the render farm then renders whichever file each status points at. Projects with no text layers are skipped for the text-off pass. Set up the relay URL/token first in Settings.

Build the Textless Sequence

Once your render-farm graphics are done (see the Render Farm stage), load your texted sequence XML here: the app swaps every texted graphic's file path to its _TEXTLESS render and saves a new XML. Import that into Premiere (File → Import) and a fully-linked TEXTLESS sequence appears — same cuts, same timecodes. Export your textless master from it, then use the QC/build tools above to finish it.

Fully clean version (no graphic at all). When text sits on a graphic — a lower-third bar, a blur box, a text-message bubble — the spec wants BOTH a textless-graphic version (bar stays, text gone) and a fully clean one with no graphic whatsoever. For on-screen overlays that needs no rendering: this disables the graphic clips in a copy of your sequence. Import it, export, and you have the clean plate.

Verify with OCR. After you export the textless master, the app can watch it: samples a frame every few seconds and reads any text it finds. Bodycam footage has camera-burned timestamps, so use the ignore strips to skip where the OSD lives; whatever remains in the report is either leftover graphics to fix, or ignorable OSD you can dismiss by eye. A 45-min episode at 5s intervals takes roughly 10–20 minutes.

Render Farm

The Render Farm stage queues each AE project on the render farm through one shared relay — this app never holds a Notion or Dropbox credential itself. It disables text layers locally when needed (the only part that has to happen on this machine), converts the file's local path to a Dropbox path, and sends a request to the relay below, which does the rest.
